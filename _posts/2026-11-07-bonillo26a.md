title: 'Table-based Probability Trees: a New Hybrid Potential Representation for Probabilistic
  Inference in Graphical Models'
section: papers
abstract: 'Probabilistic inference in graphical models, such as Bayesian and Markov
  networks, has traditionally relied either on tabular representations of conditional
  probability distributions (CPDs) or on probability trees. Tables offer straightforward
  marginalization and combination at the cost of exponential memory in the number
  of variables, while pure probability trees exploit zero entries and repeated subdistributions
  to achieve compact representations, but their arithmetic is subject to structural
  overhead when non-zero subtrees dominate. This paper introduces Table-based Probability
  Tree (TBPT) potentials as a hybrid potential representation that unifies both paradigms
  within a single, flexible data structure: a rooted ordered tree in which internal
  nodes are discrete random-variable selectors as usual, and terminal nodes are not
  only scalar values, but also table nodes storing multidimensional arrays covering
  the variables below a given branching point. After formalizing the operations to
  be applied in these potentials, empirical evaluation on standard UAI competition
  benchmarks is conducted by using the TBPT structure running exact inference via
  variable elimination (VE). This data structure is useful in cases in which potential
  have a high zero percentage. We propose to compute the total set of zeros in advance
  with a previous Boolean propagation.'
